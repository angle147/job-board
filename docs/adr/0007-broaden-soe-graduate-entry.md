# ADR 0007：放宽国企校招正式入栏条件

国企校招正式栏从“明确2027届 + 具体岗位 + 专业适配 + 明确截止日期 + 官方证据”调整为“明确2027届或届次待核验的应届/校园招聘属性 + 官方证据”。

具体岗位、专业匹配和明确截止日期不再作为入栏门槛，字段缺失时仍如实展示，最终是否投递由用户判断。宽口径不接收明确面向 2026 届或其他非 2027 届的记录；未写明届次的应届或校园招聘保留并标记待核验。第三方来源仍只作为待核验线索；纯社会招聘、硬性党员限制、工作形态一票否决、经历限制、初次就业限制和仅限博士等排除规则保持不变。

公务员和事业编板块不采用本次放宽，继续执行原有专业、届别、岗位和日期核验逻辑。
