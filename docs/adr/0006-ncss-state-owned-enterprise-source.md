# ADR 0006：接入国家大学生就业服务平台国企专题

教育部国家大学生就业服务平台的国有企业招聘专题具备公开、无需登录、数据直接嵌入页面和覆盖全国国企等特点。看板将其作为官方发现源，每日同时检查 2027 届和 2026 届专题。

采集成功条件不是页面返回 HTTP 200，而是能够解析非空 `comsList`，且每条记录至少包含企业、招聘标题和报名链接。2027 届专题尚未发布时允许 404，不视为整个来源失败；已发布专题结构异常或全部目标专题不可用时退出失败并保留旧数据。

页面响应编码曾在 UTF-8 与 GB18030 之间切换，采集器先严格尝试 UTF-8，失败后回退 GB18030，避免乱码导致日期和届别判断失效。

专题提供的是招聘批次信息，不保证具有专业和岗位级条件。记录仍进入统一资格筛选，缺少专业或具体岗位证据时进入人工审核；已截止和非目标届别记录按现有规则清理或排除。

同批扩源另接入国务院国资委人才招聘静态栏目。该栏目当前直接发布 2027 届央企招聘公告，使用独立输出文件和来源标识；只有解析到官方详情链接、标题和发布日期时才更新数据。
