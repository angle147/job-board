# 个性化国企与编制机会看板

面向 2027 届个人资格画像的全国国企校招、国考、省考和事业编机会看板。全国收录、山东优先，尤其关注济南及周边区县属国企和区县事业编。每日流水线先更新原始来源，再生成三个派生列表：

- **国企校招**：已拆分到具体岗位、具有官方证据且资格可确认的国企岗位。
- **国考 / 省考 / 事业编**：已拆分到具体岗位、用工性质符合且资格可确认的编制类岗位。
- **待处理**：所有制、岗位拆分、专业、学历、届别、工作形态或官方证据尚需人工核验的线索。
- **济南线下招聘**：只保留实体地点在济南的双选会、企业宣讲会等活动，提供活动横条和计划参加月历。

当前正式列表为零时，表示现有数据没有达到“具体岗位 + 官方证据 + 资格适配”的门槛，不会用旧公告或第三方线索补数。

## 数据架构

`data/jobs_*.js`、`data/exams.js` 等文件是各采集源的只读输入；`build_personal_board.py` 每日从这些输入生成：

- `data/board_soe.js`
- `data/board_public.js`
- `data/board_review.js`

个人资格只保存在被 Git 忽略的 `USER_PROFILE.local.md`，不会进入网页、提交记录或推送正文。排除明细保存在本地 `.board_excluded.json`，同样不提交。

## 来源状态

- 正常：山东省国资委、济南市国资委招聘专栏、央企招聘公告、山东高速、山东港口、中国铁路人才招聘网、中国公共招聘网事业单位、应届生求职网、海投网、国考职位。
- 发现线索：第三方招聘站内容只有在可反查官方原文时才可进入正式列表。
- 已禁用：51job（原外部采集项目和数据库已不存在）；微博（依赖临时 Cookie，运行时间不稳定）。

单源失败不会阻断其他源。国考源仅周日更新；个性化派生列表在每日流水线末尾统一重建。

## 济南地方国企来源

`local_soe_sources.json` 登记济南市国资委、济南市人社局国企招聘动态和12个区县政府官方入口。`scrape_local_soe.py` 已稳定适配两个市级 JPaas 栏目、历下区政府 JSearch，以及莱芜区和平阴县政府信息公开检索，并生成 `data/jobs_local_soe.js`；其余区县入口在找到可验证招聘栏目或公开接口前保持“待定位”，不会把首页可访问误报为采集成功。济南人社动态只收标题明确包含央企、国企、省属、市属、区属或县属企业的招聘信息，排除事业单位和普通招聘会。站内检索结构可用但没有真实招聘公告时记录为成功0条，不把规划、工作报告等仅提及国企的页面伪装成岗位。

地方国企记录单独保存实际用工单位、签约主体、用工形式、国资关系和所有制证据。招聘公告来自国资委栏目但具体控制层级尚未补齐时标记“控制关系待核验”，进入待处理队列，不直接冒充资格已确认的正式国企岗位。来源失败时保留上一次成功数据，并在本地健康文件中记录异常。

## 济南线下招聘

`offline_event_sources.json` 是驻济高校及公共就业来源注册表，`scrape_offline_events.py` 按平台族采集并生成：

- `data/offline_events.js`：尚未结束的济南线下活动。
- `data/offline_sources.js`：不含错误详情的公开来源健康状态。
- `.offline_source_health.json`：本地完整健康状态，Git 忽略。
- `.offline_event_reminders.json`：飞书提醒去重状态，Git 忽略。

每天9点、17点采集活动；新活动和企业名单公布可在两次运行中提醒，7/3/1天和当天提醒只在早间发送。单源失败或页面改版时保留上次成功数据，不以空数组覆盖。网页中的“计划参加”只保存在当前浏览器，不跨设备同步。
