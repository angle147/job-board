# 使用 Supabase 承载班级成员个人状态同步

## 状态

已接受并部署（2026-09-03），取代 ADR-0004 的公开访问方案。

## 背景

Cloudflare Worker 与 D1 已完成实现和本地测试，但当前网络访问 `workers.dev` 出现 TLS 握手失败，且维护者没有可绑定的自定义域名。公开看板需要一个无需自有域名、可从当前网络访问的托管后端。

## 决策

继续由 GitHub Pages 承载公共看板，个人同步后端迁移到 Supabase：Edge Function 提供与现有 `sync-client.js` 兼容的 `/api/*` 接口，Postgres 保存账号、会话、个人状态和管理员汇总数据。

所有同步表启用 RLS；`anon` 和 `authenticated` 不具有表及序列权限，浏览器不能直接访问数据库，只有 Edge Function 使用的 `service_role` 获得访问权。函数关闭 Supabase JWT 校验，因为应用使用自己签发并以 SHA-256 摘要保存的 30 天会话令牌。成员密码继续使用 PBKDF2-SHA-256（210000 次）和独立随机盐。

跨域请求只允许 `https://angle147.github.io`。管理员凭据、班级邀请码和限频密钥仅保存在 Supabase Secrets，本地部署副本和临时访问令牌均由 Git 忽略。

管理员界面由 GitHub Pages 的 `admin.html` 承载并调用相同 Edge Function API。Supabase 网关会把函数直接返回的 HTML 标记为 `text/plain`，因此函数内置 `/admin` 页面不作为正式入口。

## 验证

线上集成测试覆盖注册、账号名大小写不敏感登录、第二设备读取、岗位状态与线下计划同步、管理员人数统计、一次性密码重置、旧会话失效和成员删号；测试账号在流程末尾删除。

## 后果

维护者电脑无需持续开机，也不保存全班数据库。Supabase 免费项目可能在长期无活动时暂停，需要定期健康检查；Cloudflare 资源暂不删除，作为未启用的备选实现保留。

# 游客试用边界补充

未登录状态下，报名/公告链接、岗位状态、线下计划和 CSV 导出共用一个浏览器本地计数器。前 19 次允许执行，第 20 次起阻止并引导注册。计数不上传服务端；管理员仍只能看到注册总人数及登录活跃人数，不能看到游客浏览或具体成员操作。
